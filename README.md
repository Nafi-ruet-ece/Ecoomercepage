# E-Commerce Web Application (Node.js, Express, Supabase)

A modular, scalable full-stack e-commerce web application built using **Node.js**, **Express.js**, and **Supabase (PostgreSQL)**. 

---

## Project Vision & Architecture Roadmap
This project is being developed incrementally into a full-featured e-commerce platform. 

### Architecture Guidelines for Development:
- **Clean Entry Point**: `server.js` remains a lightweight traffic controller/hub (~25 lines). Never dump feature logic directly into `server.js`.
- **Modular MVC Pattern**:
  - `config/`: Database clients, third-party integrations (e.g., `supabase.js`).
  - `routes/`: Express routers mapping URLs to controllers (e.g., `authRoutes.js`, `productRoutes.js`).
  - `controllers/`: Business logic, database queries, and response formatting (e.g., `authController.js`, `productController.js`).
  - `public/`: Frontend assets, HTML/CSS pages, and upcoming React components.
- **Roadmap / Next Steps**:
  1. **Products Catalog**: Dedicated category pages (e.g., Shirts, Apparel), product detail views, inventory query via Supabase.
  2. **Frontend Evolution**: Gradual transition/integration of product listings and cart state into **React**.
  3. **Cart & Orders**: Shopping cart management, order history, and checkout flow.

```text
├── .env.example            # Template for environment variables
├── .gitignore              # Ignores .env and node_modules/

├── package-lock.json
├── README.md               # Documentation & project architecture
└── server.js               # Clean master entry point
```

---

## Features
- **User Registration (`/signup`)**: Validates Name, Age, Email, and Password and inserts user records into Supabase.
- **User Authentication (`/login`)**: Verifies credentials against the Supabase `users` table.
- **Responsive UI**: Modern card layout with real-time feedback, button loading states, and error alerts.
- **Modular Routing**: Features are divided into separate controllers and routers for clean scalability.
- **Environment Protection**: Secrets are safeguarded via `dotenv` and excluded from source control.

## Getting Started

### 1. Installation
```bash
npm install
```

### 2. Environment Configuration
Create a `.env` file in the root directory:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_supabase_key
PORT=3000
```

### 3. Database Table (`users`)
```sql
CREATE TABLE public.users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  age INTEGER NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 4. Running the Application
```bash
node server.js
```
The server will start at `http://localhost:3000`.
