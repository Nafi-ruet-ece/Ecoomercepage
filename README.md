# Express.js & Supabase Authentication System

A minimal full-stack authentication web application built using **Node.js**, **Express.js**, and **Supabase (PostgreSQL)**, featuring client-side and server-side validation for user login and signup.

---

## Features
- **User Registration (`/signup`)**: Collects Name, Age, Email, and Password and creates a user record in the Supabase PostgreSQL database.
- **User Login (`/`)**: Authenticates registered users against credentials stored in Supabase.
- **Clean UI & Feedback**: Responsive CSS card UI with real-time feedback, button loading states, and error handling.
- **RESTful Backend**: Built with Express.js handling JSON and form-urlencoded payloads.
- **Environment Variable Protection**: Database credentials safely managed using `dotenv`.

---

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL (hosted via Supabase)
- **Configuration**: dotenv

---

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Create a `.env` file in the root directory (refer to `.env.example`):
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_supabase_key
PORT=3000
```

### 4. Database Setup (Supabase)
Create a `users` table in your Supabase database:
```sql
CREATE TABLE public.users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  age INTEGER NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```
*(Ensure Row-Level Security has appropriate policies or is disabled for anon access).*

### 5. Run the Server
```bash
node server.js
```
The server will start at `http://localhost:3000`.
